# 自主进化与记忆优化 Skill

## 描述
定期对知识库内容进行归纳、总结、优化，自动沉淀高频有效技能/Prompt/工作流，持续提升Agent能力。

## 输入参数
- 当前知识库内容

## 输出
- 优化后的知识库、技能库

## 主要流程
1. 分析知识库内容
2. 归纳总结高频有效内容
3. 自动沉淀为技能/Prompt/工作流
4. 优化知识库结构

## 适用场景
- Agent自我成长
- 知识库持续进化
